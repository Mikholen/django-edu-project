# PhysLab — Образовательный тренажер по физике

**PhysLab** — это веб-приложение на Django, разработанное для автоматизации проверки знаний по физике. Проект позволяет учителям добавлять задачи через панель администратора, а ученикам — решать их с мгновенной автопроверкой ответа.

---

## Основной функционал

Проект реализует следующие ключевые возможности:
* **Каталог задач:** Динамический список всех доступных физических задач из базы данных.
* **Интерактивное решение:** Отдельная страница для каждой задачи.
* **Система автопроверки:** Мгновенное сравнение введенного пользователем ответа с эталонным (с учетом математической погрешности $0.1$).
* **Личный кабинет:** Форма регистрации пользователей для будущего отслеживания прогресса.
* **Статистика:** Аналитическая страница с общими данными по учебным материалам.

* **Backend:** Python 3.12, Django 5.x / 6.x
* **Frontend:** HTML5, Bootstrap 5
* **Database:** SQLite3

## Установка и запуск

1. **Клонируйте репозиторий:**
   ```bash
   git clone git@github.com:Mikholen/django-edu-project.git
   cd django-edu-project

2. **Создайте локальную среду:**
   **Для Windows:**
   ```bash
   python -m venv .venv
   .venv\Scripts\activate

   **Для Linux/macOS:**
   ```bash
   python3 -m venv .venv
   source .venv/bin/activate

3. **Установите все необходимые зависимости:**
    ```bash
    pip install --upgrade pip
    pip install -r requirements.txt

4. **Подготовьте базу данных:**
    ```bash
    python manage.py migrate

5. **Создайте учетную запись администратора (необходимо для добавления новых задач):**
    ```bash
    python manage.py createsuperuser

6. **Запустите локальный сервер:**
    ```bash
    python manage.py runserver

Приложение будет доступно по адресу: http://127.0.0.1:8000/tasks/
