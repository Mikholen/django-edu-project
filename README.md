## О проекте
**PhysLab** — это образовательная веб-платформа, разработанная для закрепления теоретических знаний физики через практику решения расчетных задач. Проект представляет собой интерактивную среду, где пользователи могут тренироваться в решении задач из ключевых разделов физики: механики, термодинамики, оптики и электродинамики.

### Какую проблему решает проект?
Многие учащиеся испытывают трудности не из-за незнания формул, а из-за отсутствия инструмента для мгновенной верификации своих вычислений. **PhysLab** решает эту проблему:
* **Мгновенная обратная связь:** Система автоматически проверяет численный ответ пользователя с учетом допустимой погрешности ($\pm 0.1$).
* **Снижение порога входа:** Чистый интерфейс и наличие подсказок (hints) помогают в самостоятельном обучении без участия преподавателя.
* **Доступность:** Адаптивная верстка позволяет эффективно использовать тренажер как на десктопах, так и на мобильных устройствах.

## Ключевые возможности
* **Динамическая база задач:** Все условия, ответы и подсказки хранятся в БД (SQLite), что позволяет легко масштабировать контент.
* **Интеллектуальная валидация:** Реализована кастомная логика сравнения чисел с плавающей точкой в Django Views, исключающая штрафы за незначительные ошибки округления.
* **Система авторизации:** Полноценный цикл регистрации и входа для персонализации опыта пользователя.
* **Наследование шаблонов:** Использование архитектуры DRY (Don't Repeat Yourself) для единообразия интерфейса.
* **Качество кода:** 100% соответствие стандартам PEP 8, подтвержденное линтером **Pylint**.

## Технологический стек
* **Backend:** Python, Django 4.2+
* **Frontend:** HTML5, CSS3, Bootstrap 5
* **Database:** SQLite3
* **Качество и контроль:** Pylint, Git

## Установка и запуск

1. **Клонируйте репозиторий:**
   ```bash
   git clone git@github.com:Mikholen/django-edu-project.git
   cd django-edu-project

2. **Создайте локальную среду:**
   
   **Для Windows:**
   ```bash
   python -m venv .venv
   .venv\Scripts\activate
   ```

   **Для Linux/macOS:**
   ```bash
   python3 -m venv .venv
   source .venv/bin/activate

3. **Установите все необходимые зависимости:**
    ```bash
    pip install --upgrade pip
    pip install -r requirements.txt

4. **Подготовьте базу данных:**
    ```bash
    python manage.py migrate

5. **Создайте учетную запись администратора (необходимо для добавления новых задач):**
    ```bash
    python manage.py createsuperuser

6. **Запустите локальный сервер:**
    ```bash
    python manage.py runserver

Приложение будет доступно по адресу: http://127.0.0.1:8000/tasks/
